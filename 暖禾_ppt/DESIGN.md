# DESIGN.md — 暖禾家具项目成果展示

## 1. 画布与母版（默认 A/B/C 三区）
| 母版区 | 垂直位置 | 高度 | 内容规则 |
| :--- | :--- | :--- | :--- |
| A · 标题块 | 0–120px | 120px（上 padding 20） | 主标题 32–36px bold，左侧色条 6px |
| B · 内容区 | 120–660px | 540px 可用 | 正文 / 卡片 / 占位图 / 列表 |
| C · 页脚条 | 660–720px | 60px（下 padding 20） | 左：暖禾家具 · 项目成果展示；右：页码 NN / 08 |

- 页面 padding：上下 20px、左右 64px（封面/结束页自定义）。
- 内容页标题块统一：左侧 6px 实木色竖条 + 主标题 + 副标。

## 2. 颜色系统（≤4 hex + 中性）
| 角色 | hex | 用途 |
| :--- | :--- | :--- |
| 背景 paper | `#FBF7F1` | 全篇底色（暖宣纸米） |
| 主色 walnut | `#2A211A` | 标题、深色大色块、正文主色 |
| 辅色 wood | `#B07A4F` | 卡片底色、分隔、图标容器 |
| 强调 terracotta | `#C76B3A` | 巨型数字、关键标注、CTA（≤10%） |
| 中性文本 | `#5A4F45` | 正文、页脚（常规页） |

色彩面积分配：主色(深块)≤60% / 辅色≤30% / 强调≤10%；Hero 页强调可到 15–20%。
渐变：`linear-gradient(135deg, #2A211A 0%, #B07A4F 100%)` 用于封面/结束页大色块；半透明 `rgba(176,122,79,0.08)` 作卡片浅底。
