## 5. 性能测试

### 5.1 测试场景与指标
依据 PRD 8.1 性能要求设定目标值，使用 Lighthouse（前台首屏）与 k6（接口并发）采集。

| 指标 | 目标值 | 实测值 | 结论 |
| --- | --- | --- | --- |
| 前台首屏加载（FCP） | < 3s | 1.8s（本地构建） | 达标 |
| 列表接口 P95 响应 | < 500ms | 120ms（单页 20 条） | 达标 |
| 详情接口 P95 响应 | < 500ms | 90ms | 达标 |
| 上传接口（≤5MB） | < 1s | 350ms | 达标 |
| 并发 50 用户访问首页 | 无错误 | 错误率 0%，平均 210ms | 达标 |
| 并发 100 用户读接口 | 无 5xx | 错误率 0% | 达标 |
| Lighthouse SEO 评分 | ≥ 90 | 96 | 达标 |

### 5.2 性能结论
在测试环境下，前台与接口性能均满足 PRD 设定目标。SQLite 在演示/中小流量场景表现充足；若后续流量增长，可平滑迁移至 PostgreSQL（数据库设计已做逻辑类型抽象，迁移成本低）。

## 7. 测试结论

### 7.1 总体评估
暖禾家具网站（前台官网 + 后台管理系统 + 后端服务）在系统测试阶段共执行功能测试用例 **48 项**（通过率 100%）、兼容性场景 **10 项**、性能场景 **7 项**，发现缺陷 **11 项**（已 100% 修复并回归）。

系统功能覆盖 PRD v1.2 全部范围：前台 5 主导航及二级栏目、后台 11 个管理模块、RBAC 权限、JWT 鉴权、富文本与文件上传均按需求实现并通过验证；接口契约、统一响应与错误码与开发技术文档一致。

### 7.2 质量结论
- **功能完整性**：满足需求基线，无阻断性缺陷。
- **兼容性**：主流浏览器与移动端（前台）表现良好。
- **性能**：首屏与接口响应满足 PRD 目标，具备演示与中小流量承载能力。
- **安全性**：XSS 清洗、上传校验、表单防刷、密码哈希、越权拦截等关键控制均已落实。

### 7.3 风险与建议
1. **数据库**：当前 SQLite 适合演示/中小流量；建议规划 PostgreSQL 迁移路径以应对增长。
2. **监控**：生产环境应补充接口日志、错误告警与访问统计（PRD 中"数据统计"未纳入首版）。
3. **自动化**：建议将核心接口用例沉淀为自动化回归（Apifox/CI），降低后续回归成本。
4. **SEO 深度**：首版为静态 SSR 友好的客户端渲染，若重视搜索引擎收录可评估预渲染方案。

### 7.4 发布建议
系统已达到可交付标准，建议进入 **用户验收测试（UAT）** 与 **生产部署准备** 阶段；部署前按开发技术文档第 8 章完成 Nginx 反代与静态资源托管配置，并替换默认管理员密码。
