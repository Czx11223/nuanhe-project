## 1. 项目概述与技术栈

### 1.1 目标与范围（引用 PRD 1.1–1.3）
- 建设 **前台企业官网**（展示型 + 留言咨询）与 **后台管理系统**（RBAC 多角色内容运营）。
- 不含电商、会员、第三方登录、多语言、生产部署落地（详见 PRD 1.3 Out of Scope）。
- 工程组织：单仓库下分 `api/`、`backend/`、`frontend/` 三目录，三者解耦（详见 PRD 第 10 章）。

### 1.2 技术栈与版本

| 层 | 技术 | 版本/说明 |
| --- | --- | --- |
| 后端（Api）框架 | FastAPI | 0.110+ |
| ASGI 服务器 | Uvicorn（开发）/ Gunicorn+Uvicorn worker（生产） | uvicorn 0.29+ |
| ORM | SQLAlchemy | 2.x（声明式 `Mapped` 注解） |
| 数据校验 | Pydantic v2 | 请求/响应 Schema |
| 数据库 | SQLite | 文件库 `api/app.db`，零运维 |
| 鉴权 | python-jose（JWT）+ passlib[bcrypt] | Access Token 默认 2h |
| 富文本存储 | TipTap 输出 HTML + 后端（Api）白名单清洗 | 防 XSS |
| 前台前端 | React 18 + TypeScript + Vite + Tailwind CSS | Tailwind 3.4 |
| 后台（Backend）前端 | React 18 + TypeScript + Vite + Ant Design 5 | antd 5.x |
| 状态管理 | Zustand（后台登录态）/ Context（前台） | — |
| 接口文档 | Swagger（FastAPI 自动 `/docs`）+ ReDoc `/redoc` | — |
| 包管理 | npm | 前后台各一 `package.json` |

### 1.3 三目录职责（引用 PRD 第 10 章）

| 目录 | 技术 | 职责 | 接口消费 |
| --- | --- | --- | --- |

## 3. 数据库设计

### 3.1 ER 关系概览
```
admin_user ──(role_id)──> role
product    ──(category_id)──> product_category
news / case / recruitment / banner / about_content / message / site_setting  (相对独立内容表)
```
- 仅 `admin_user→role`、`product→product_category` 存在外键；其余内容为独立内容表，便于按需扩展。
- 共 11 张表（见 PRD 6.2）：`admin_user`、`role`、`banner`、`site_setting`、`about_content`、`product_category`、`product`、`news`、`case`、`recruitment`、`message`。

### 3.2 建表 SQL（SQLite，可直接执行）
```sql
-- ============ 权限与账户 ============
CREATE TABLE role (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    name        TEXT    NOT NULL,
    code        TEXT    NOT NULL UNIQUE,   -- super_admin / editor / operator
    permissions TEXT    NOT NULL DEFAULT '[]', -- JSON 数组
    description TEXT
);

CREATE TABLE admin_user (
    id            INTEGER PRIMARY KEY AUTOINCREMENT,
    username      TEXT    NOT NULL UNIQUE,
    password_hash TEXT    NOT NULL,
    real_name     TEXT,
    role_id       INTEGER NOT NULL,
    status        INTEGER NOT NULL DEFAULT 1, -- 1 启用 / 0 禁用
    created_at    DATETIME DEFAULT CURRENT_TIMESTAMP,
    last_login_at DATETIME,
    FOREIGN KEY (role_id) REFERENCES role(id)
);

-- ============ 内容与展示 ============
CREATE TABLE banner (
    id         INTEGER PRIMARY KEY AUTOINCREMENT,
    title      TEXT,
    image_url  TEXT,
    link_url   TEXT,
    sort       INTEGER NOT NULL DEFAULT 0,
    status     INTEGER NOT NULL DEFAULT 1, -- 1 启用 / 0 停用
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE site_setting (
    id            INTEGER PRIMARY KEY CHECK (id = 1), -- 单条固定
    site_name     TEXT,
    logo_url      TEXT,
    icp           TEXT,
    address       TEXT,
    phone         TEXT,
    email         TEXT,
    business_hours TEXT,
    latitude      REAL,
    longitude     REAL,
    seo_title     TEXT,
    seo_keywords  TEXT,
    seo_description TEXT
);

CREATE TABLE about_content (
    id        INTEGER PRIMARY KEY AUTOINCREMENT,
    section   TEXT    NOT NULL,  -- about_暖禾 / history / brand
    title     TEXT,
    content   TEXT,               -- 富文本 HTML
    image_url TEXT,
    sort      INTEGER NOT NULL DEFAULT 0,
    status    INTEGER NOT NULL DEFAULT 1
);

CREATE TABLE product_category (
    id        INTEGER PRIMARY KEY AUTOINCREMENT,
    name      TEXT    NOT NULL,
    parent_id INTEGER,            -- 一级为 NULL
    sort      INTEGER NOT NULL DEFAULT 0,
    status    INTEGER NOT NULL DEFAULT 1,
    FOREIGN KEY (parent_id) REFERENCES product_category(id)
);

CREATE TABLE product (
    id              INTEGER PRIMARY KEY AUTOINCREMENT,
    category_id     INTEGER,
    name            TEXT    NOT NULL,
    series          TEXT,
    code            TEXT,
    reference_price REAL,
    cover_image     TEXT,
    gallery         TEXT,   -- JSON 数组
    description     TEXT,   -- 富文本 HTML
    specs           TEXT,
    is_recommended  INTEGER NOT NULL DEFAULT 0, -- 1 推荐
    sort            INTEGER NOT NULL DEFAULT 0,
    status          INTEGER NOT NULL DEFAULT 1, -- 1 上架 / 0 下架
    created_at      DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (category_id) REFERENCES product_category(id)
);

CREATE TABLE news (
    id            INTEGER PRIMARY KEY AUTOINCREMENT,
    title         TEXT    NOT NULL,
    category      TEXT    NOT NULL,  -- 企业新闻 / 行业资讯
    cover_image   TEXT,
    summary       TEXT,
    content       TEXT,               -- 富文本 HTML
    author        TEXT,
    publish_status INTEGER NOT NULL DEFAULT 0, -- 1 已发布 / 0 草稿
    published_at  DATETIME,
    views         INTEGER NOT NULL DEFAULT 0,
    sort          INTEGER NOT NULL DEFAULT 0,
    created_at    DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at    DATETIME DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE case (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    title       TEXT    NOT NULL,
    category    TEXT,               -- 项目案例 / 客户案例
    cover_image TEXT,
    summary     TEXT,
    content     TEXT,               -- 富文本 HTML
    sort        INTEGER NOT NULL DEFAULT 0,
    status      INTEGER NOT NULL DEFAULT 1, -- 1 启用 / 0 停用
    created_at  DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at  DATETIME DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE recruitment (
    id           INTEGER PRIMARY KEY AUTOINCREMENT,
    type         INTEGER NOT NULL,  -- 1 社会招聘 / 2 校园招聘
    title        TEXT    NOT NULL,
    department   TEXT,
    location     TEXT,
    description  TEXT,               -- 岗位职责（富文本）
    requirements TEXT,
    status       INTEGER NOT NULL DEFAULT 1, -- 1 招聘中 / 0 停用
    sort         INTEGER NOT NULL DEFAULT 0,
    created_at   DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at   DATETIME DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE message (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    name        TEXT    NOT NULL,
    phone       TEXT,
    email       TEXT,
    type        TEXT    NOT NULL,   -- 留言/预约/咨询/简历投递
    content     TEXT,
    status      INTEGER NOT NULL DEFAULT 0, -- 0 待处理 / 1 已处理 / 2 已忽略
    reply       TEXT,
    created_at  DATETIME DEFAULT CURRENT_TIMESTAMP,
    handled_at  DATETIME
);

-- ============ 迁移版本表 ============
CREATE TABLE schema_version (
    version INTEGER PRIMARY KEY,
    applied_at DATETIME DEFAULT CURRENT_TIMESTAMP
);
INSERT INTO schema_version(version) VALUES (1);

-- ============ 索引 ============
CREATE INDEX idx_product_category ON product(category_id);
CREATE INDEX idx_news_category ON news(category);
CREATE INDEX idx_news_publish ON news(publish_status, published_at);
CREATE INDEX idx_case_status ON case(status);
CREATE INDEX idx_recruitment_type ON recruitment(type, status);
CREATE INDEX idx_message_status ON message(status);
CREATE INDEX idx_admin_role ON admin_user(role_id);
```

### 3.3 SQLAlchemy 模型样例（`api/app/models.py`）
```python
from datetime import datetime
from sqlalchemy import String, Integer, Float, Text, Boolean, ForeignKey, DateTime
from sqlalchemy.orm import DeclarativeBase, Mapped, mapped_column, relationship

class Base(DeclarativeBase):
    pass

class Role(Base):
    __tablename__ = "role"
    id: Mapped[int] = mapped_column(primary_key=True)
    name: Mapped[str] = mapped_column(String(50))
    code: Mapped[str] = mapped_column(String(50), unique=True)
    permissions: Mapped[str] = mapped_column(Text, default="[]")  # JSON str
    description: Mapped[str | None] = mapped_column(Text, nullable=True)

class AdminUser(Base):
    __tablename__ = "admin_user"
    id: Mapped[int] = mapped_column(primary_key=True)
    username: Mapped[str] = mapped_column(String(50), unique=True)
    password_hash: Mapped[str] = mapped_column(String(255))
    real_name: Mapped[str | None] = mapped_column(String(50), nullable=True)
    role_id: Mapped[int] = mapped_column(ForeignKey("role.id"))
    status: Mapped[int] = mapped_column(Integer, default=1)
    created_at: Mapped[datetime] = mapped_column(DateTime, default=datetime.utcnow)
    last_login_at: Mapped[datetime | None] = mapped_column(DateTime, nullable=True)
    role: Mapped["Role"] = relationship("Role")

class Banner(Base):
    __tablename__ = "banner"
    id: Mapped[int] = mapped_column(primary_key=True)
    title: Mapped[str | None] = mapped_column(String(100), nullable=True)
    image_url: Mapped[str | None] = mapped_column(String(255), nullable=True)
    link_url: Mapped[str | None] = mapped_column(String(255), nullable=True)
    sort: Mapped[int] = mapped_column(Integer, default=0)
    status: Mapped[int] = mapped_column(Integer, default=1)
    created_at: Mapped[datetime] = mapped_column(DateTime, default=datetime.utcnow)
    updated_at: Mapped[datetime] = mapped_column(DateTime, default=datetime.utcnow,
                                                  onupdate=datetime.utcnow)

class SiteSetting(Base):
    __tablename__ = "site_setting"
    id: Mapped[int] = mapped_column(Integer, primary_key=True)
    site_name: Mapped[str | None] = mapped_column(String(100), nullable=True)
    logo_url: Mapped[str | None] = mapped_column(String(255), nullable=True)
    icp: Mapped[str | None] = mapped_column(String(50), nullable=True)
    address: Mapped[str | None] = mapped_column(String(255), nullable=True)
    phone: Mapped[str | None] = mapped_column(String(50), nullable=True)
    email: Mapped[str | None] = mapped_column(String(100), nullable=True)
    business_hours: Mapped[str | None] = mapped_column(String(100), nullable=True)
    latitude: Mapped[float | None] = mapped_column(Float, nullable=True)
    longitude: Mapped[float | None] = mapped_column(Float, nullable=True)
    seo_title: Mapped[str | None] = mapped_column(String(255), nullable=True)
    seo_keywords: Mapped[str | None] = mapped_column(String(255), nullable=True)
    seo_description: Mapped[str | None] = mapped_column(String(255), nullable=True)

class AboutContent(Base):
    __tablename__ = "about_content"
    id: Mapped[int] = mapped_column(primary_key=True)
    section: Mapped[str] = mapped_column(String(50))
    title: Mapped[str | None] = mapped_column(String(100), nullable=True)
    content: Mapped[str | None] = mapped_column(Text, nullable=True)
    image_url: Mapped[str | None] = mapped_column(String(255), nullable=True)
    sort: Mapped[int] = mapped_column(Integer, default=0)
    status: Mapped[int] = mapped_column(Integer, default=1)

class ProductCategory(Base):
    __tablename__ = "product_category"
    id: Mapped[int] = mapped_column(primary_key=True)
    name: Mapped[str] = mapped_column(String(50))
    parent_id: Mapped[int | None] = mapped_column(Integer, ForeignKey("product_category.id"), nullable=True)
    sort: Mapped[int] = mapped_column(Integer, default=0)
    status: Mapped[int] = mapped_column(Integer, default=1)

class Product(Base):
    __tablename__ = "product"
    id: Mapped[int] = mapped_column(primary_key=True)
    category_id: Mapped[int | None] = mapped_column(Integer, ForeignKey("product_category.id"), nullable=True)
    name: Mapped[str] = mapped_column(String(100))
    series: Mapped[str | None] = mapped_column(String(50), nullable=True)
    code: Mapped[str | None] = mapped_column(String(50), nullable=True)
    reference_price: Mapped[float | None] = mapped_column(Float, nullable=True)
    cover_image: Mapped[str | None] = mapped_column(String(255), nullable=True)
    gallery: Mapped[str | None] = mapped_column(Text, nullable=True)  # JSON
    description: Mapped[str | None] = mapped_column(Text, nullable=True)
    specs: Mapped[str | None] = mapped_column(Text, nullable=True)
    is_recommended: Mapped[int] = mapped_column(Integer, default=0)
    sort: Mapped[int] = mapped_column(Integer, default=0)
    status: Mapped[int] = mapped_column(Integer, default=1)
    created_at: Mapped[datetime] = mapped_column(DateTime, default=datetime.utcnow)
    updated_at: Mapped[datetime] = mapped_column(DateTime, default=datetime.utcnow,

class Case(Base):

    id: Mapped[int] = mapped_column(primary_key=True)
```

### 3.4 种子数据（`api/seed.py`，首次初始化执行）
```python
from app.db import SessionLocal
from app.models import Role, AdminUser, SiteSetting, ProductCategory
from app.security import hash_password

def seed():
    db = SessionLocal()
    # 角色
    super_admin = Role(name="超级管理员", code="super_admin",
                        permissions='["*"]', description="全部权限")
    editor = Role(name="内容编辑", code="editor",
                  permissions='["banner","about","product_category","product","news","case","recruitment"]')
    operator = Role(name="运营", code="operator",
                    permissions='["message","site_setting"]')
    db.add_all([super_admin, editor, operator])
    db.flush()
    # 默认管理员
    admin = AdminUser(username="admin", password_hash=hash_password("admin123"),
                      real_name="系统管理员", role_id=super_admin.id, status=1)
    db.add(admin)
    # 站点设置单条
    db.add(SiteSetting(id=1, site_name="暖禾家具",
                        address="示例市示例区示例路1号", phone="400-000-0000",
                        email="contact@暖禾.example"))
    # 示例分类
    for name in ["胡桃禮","如意春","禧YUE","柏悦","蓝宝嘉","办公家具","软体"]:
        db.add(ProductCategory(name=name, sort=0, status=1))
    db.commit(); db.close()
```
> 权限键约定（用于 RBAC 校验）：`*`(全部)、`banner`、`about`、`product_category`、`product`、`news`、`case`、`recruitment`、`message`、`site_setting`、`admin`、`role`。

### 3.5 迁移策略
- 采用 **init SQL + `schema_version` 版本表**，不引入 Alembic（演示友好、零额外依赖）。
- 启动钩子：应用启动时检查 `schema_version`，若库不存在则执行 `init.sql` 并插入版本 1；后续升级新增 `migrations/0002_*.sql` 并在启动时按版本号顺序执行。
- 也可用 SQLAlchemy `Base.metadata.create_all` 作为开发期兜底，但生产以 `init.sql` 为准。

### 4.2 鉴权与 RBAC（`app/security.py` 样例）
```python
from datetime import datetime, timedelta
from jose import JWTError, jwt
from passlib.context import CryptContext
from fastapi import Depends, HTTPException
from fastapi.security import HTTPAuthorizationCredentials, HTTPBearer
from app.db import SessionLocal
from app.models import AdminUser, Role

SECRET = "change_me_in_prod"
ALGO = "HS256"
EXPIRE_MIN = 120

pwd = CryptContext(schemes=["bcrypt"], deprecated="auto")
bearer = HTTPBearer()

def hash_password(p): return pwd.hash(p)
def verify_password(p, h): return pwd.verify(p, h)
def create_token(user_id): 
    exp = datetime.utcnow() + timedelta(minutes=EXPIRE_MIN)
    return jwt.encode({"sub": str(user_id), "exp": exp}, SECRET, ALGO)

def get_current_user(cred: HTTPAuthorizationCredentials = Depends(bearer)):
    try:
        payload = jwt.decode(cred.credentials, SECRET, algorithms=[ALGO])
        uid = int(payload["sub"])
    except (JWTError, KeyError):
        raise HTTPException(401, "未授权或登录已过期")
    db = SessionLocal(); user = db.get(AdminUser, uid); db.close()
    if not user or user.status == 0:
        raise HTTPException(401, "账号被禁用")
    return user

def require_perm(perm: str):
    def dep(user: AdminUser = Depends(get_current_user)):
        db = SessionLocal(); role = db.get(Role, user.role_id); db.close()
        perms = role.permissions if isinstance(role.permissions, list) else __import__("json").loads(role.permissions)
        if "*" not in perms and perm not in perms:
            raise HTTPException(403, "无权限")
        return user
    return dep
```

### 4.3 统一响应与错误处理器（`app/main.py` 片段）
```python
from fastapi import FastAPI, Request
from fastapi.responses import JSONResponse
from fastapi.exceptions import RequestValidationError

app = FastAPI(title="暖禾家具 API", version="1.0")

@app.middleware("http")
async def response_wrapper(request: Request, call_next):
    resp = await call_next(request)
    if resp.headers.get("content-type","").startswith("application/json"):
        body = json.loads(resp.body)
        if "code" not in body:  # 包成统一结构
            return JSONResponse({"code":0,"data":body,"msg":"ok"}, status_code=resp.status_code)
    return resp

@app.exception_handler(RequestValidationError)
async def validation_handler(req, exc):
    return JSONResponse(status_code=422, content={"code":422,"msg":str(exc.errors())})

@app.exception_handler(HTTPException)
async def http_handler(req, exc):
    code = 401 if exc.status_code==401 else 403 if exc.status_code==403 else exc.status_code
    return JSONResponse(status_code=exc.status_code, content={"code":code,"msg":exc.detail})
```
> 统一响应：`{ "code": 0, "data": ..., "msg": "ok" }`；错误：`{ "code": <非零>, "msg": "..." }`。错误码 401/403/422/404/500（见 PRD 7.4）。

### 4.4 文件上传（`app/routers/upload.py`）
```python
import os
from fastapi import APIRouter, UploadFile, File, Depends
from app.security import require_perm

router = APIRouter(prefix="/api/upload", tags=["upload"])
ALLOWED = {"image/jpeg","image/png","image/webp"}
UPLOAD_DIR = "app/static/uploads"
MAX_SIZE = 5*1024*1024

@router.post("", dependencies=[Depends(require_perm("banner"))])
async def upload(file: UploadFile = File(...)):
    if file.content_type not in ALLOWED:
        raise HTTPException(400, "仅支持 jpg/png/webp")
    data = await file.read()
    if len(data) > MAX_SIZE:
        raise HTTPException(400, "文件大于 5MB")
    os.makedirs(UPLOAD_DIR, exist_ok=True)
    fn = f"{uuid4().hex}{os.path.splitext(file.filename)[1]}"
    with open(f"{UPLOAD_DIR}/{fn}","wb") as f: f.write(data)
    return {"code":0,"data":{"url":f"/static/uploads/{fn}"},"msg":"ok"}
```
前端通过 `<img src={VITE_API_BASE+url}>` 访问静态文件；`app/main.py` 挂载 `StaticFiles` 于 `/static`。
